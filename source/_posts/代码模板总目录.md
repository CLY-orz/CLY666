## 使用前必读

所有模板均默认以下全局定义已存在，直接复制单个函数会编译失败。请先粘贴到你的代码最上方：

```cpp
#include <bits/stdc++.h>
using namespace std;
using gg = long long;
constexpr gg MAX = 1e6 + 5;
constexpr gg mod = 1e9 + 7;
constexpr gg INF = 2e18;
constexpr double thre = 1e-7;  //用以判断两个浮点数是否相等的阈值
gg ti, ni, mi, ki, di, pi, xi, yi;
```

- `gg`：`long long` 的类型别名，避免 `int` 溢出
- `MAX`：数据规模上限，**请按题目实际范围调整**
- `mod`：常用模数 `1e9 + 7`
- `INF`：正无穷，负无穷用 `-INF`
- `thre`：浮点数相等判断阈值
- `ti, ni, mi, ...`：输入规模类变量，后缀 `i` 是 `input` 的缩写，表示由输入指定
