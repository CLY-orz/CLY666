# 自走棋数值设计

设计目标是让低费追星、中费组队和后期高费补位都有用途。角色费用表示获取成本，星级通过合成获得；两者不是同一概念。

## 属性、费用和升星

费用的基础生命/攻击系数为1 / 1.14 / 1.29 / 1.46 / 1.65，星级生命/攻击系数为1 / 1.7 / 2.8。角色技能、护甲、攻击间隔和分工还会影响实际表现，不能只按单一乘数判断胜负。

1至5费角色数量为16 / 14 / 12 / 10 / 8。当前角色费用和技能见 [ROSTER.md](ROSTER.md)。

## 羁绊

角色组合与6种基础分工各自按门槛激活。人数只计算场上不同角色；常驻关系属性仅由每种角色的一枚最高星棋子领取，相同星级时按稳定ID顺序决定，不随主副本倒下重新领取。

|基础分工|门槛|效果|
|---|---|---|
|先锋|2 / 4|先锋生命提高6 / 10%|
|强攻|2 / 4|强攻攻击提高5 / 8%|
|游击|2 / 4|游击攻速提高6 / 10%|
|术士|2 / 4|术士技能伤害提高8 / 12%|
|控场|2 / 4|控场护甲提高6 / 10|
|支援|2 / 4|支援治疗与护盾提高8 / 12%|

常驻关系加成上限分别为：生命、攻击、治疗/护盾24%，攻速18%，技能伤害28%。全部羁绊额外能量每种角色最多32，实际治疗和护盾合计最多最大生命22%；同名副本共享预算。搭档与施法主题各触发一组，共享4/6秒冷却，子预算分别为18能量和12%生命。技能本体与普通回能不占羁绊预算。

完整组合和效果见 [RELATIONSHIPS.md](RELATIONSHIPS.md)。

## 综合布阵与验证

合法持牌最多17枚，8人口时最多比较24,310组候选。评价依据真实生命、护甲、攻击间隔、星级、技能伤害/治疗/护盾、施法周期、有效羁绊和承伤分工。相同评分优先更多不同角色；高星同名副本仍可能因自身价值入选。

评分模型与真实战斗共享常驻属性计算，但不会穷举所有未来对手和全部棋盘站位，因此模型最优不等于对任意对手都必胜。

承伤覆盖只将实际近战角色算作前排，避免把远程控场误算成坦克。选定组合后，按近战前排、中程支援和远程后排侧翼安排位置，CPU 同样执行。远程普通攻击按射程结算且不附带推退，物理近战技能仍需接近；基础生命、攻击、护甲和攻击间隔随分工调整。当前具体数值见角色手册。

程序测试覆盖卡牌与技能规则、完整候选比较、同名去重、候补隔离和缓存等价性。平衡判断仍应结合实际阵容、购卡成本、搜卡与升级时间；相同星级并不代表相同投入。
