# 自走棋羁绊手册

以下是游戏中的角色组合与机制。人物、角色名称用于同人玩法，不表示现实私人关系或官方合作。

场上不同角色达到门槛后激活；候补和同名副本不增加人数。常驻关系属性只由同名角色的一枚最高星棋子领取。点游戏中的羁绊可查看当前场上、候补及缺少的成员。

## 叠加规则

梗与团体是主要羁绊，基础分工只提供少量辅助加成。同一成员从关系获得的常驻生命/攻击/治疗加成最多24%，攻速18%，技能伤害28%。整场关系额外回能最多32，实际回复与护盾合计最多最大生命22%；搭档与施法主题各触发一组并共享4 / 6秒冷却，其中回能最多18、回复与护盾最多12%。同名副本共享触发与资源预算，常驻关系属性只由一枚最高星同名棋子领取；复制不增加人数。
